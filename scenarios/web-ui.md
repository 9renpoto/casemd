# casemd Web UI シナリオテスト

## ページ表示
### 初期状態
#### デフォルトプレビューが表示される

1. `go run ./cmd/casemd serve` で Web UI を起動する。
2. ブラウザーで `http://localhost:3000/` を開く。

* [ ] ページタイトルが `casemd Preview` と表示される。
* [ ] Markdown エディターに同梱の `notes.md` サンプルが入力されている。
* [ ] Source Name 欄に `notes.md` が入力されている。
* [ ] Submit 操作を行わなくても、CSV のヘッダーと解析済み行が表示される。

#### 静的ファイルが読み込まれる

1. ブラウザーの開発者ツールで Network パネルを開く。
2. `http://localhost:3000/` を再読み込みする。

* [ ] stylesheet の読み込みに 404 エラーがない。
* [ ] JavaScript の読み込みに 404 エラーがない。
* [ ] エディター、Preview CSV ボタン、プレビューテーブルが表示される。

## プレビュー変換
### 正常系
#### 日本語 Markdown を変換する

1. Source Name を `日本語_sample-01.md` に変更する。
2. 次の Markdown を入力する（引用行は入力例であり、シナリオ自身の項目ではない）。

   > # 受入れ確認 A-01
   > ## アカウント設定
   > ### Profile 編集
   > #### 表示名の変更（全角・半角Mix）
   > 1. `user@example.com` でログインする。
   > 2. 表示名を `山田 Taro 01` に変更して保存する。
   > 3. `OK` ダイアログを閉じる。
   > * [ ] 「変更を保存しました」が画面上に表示される。
   > * [ ] 全角文字 `山田` と半角英数字 `Taro 01` が欠落せず表示される。
   > * [ ] ハイフン `-`、アンダースコア `_`、スラッシュ `/` が意図せず変換されない。

3. `Preview CSV` ボタンを選択する。

* [ ] 変換中はボタンが一時的に disabled になる。
* [ ] 成功後にステータスが `Done` になる。
* [ ] 期待する列ヘッダーがテーブルに表示される。
* [ ] 見出し、手順、確認項目に含めた日本語と半角文字がそのまま表示される。
* [ ] Source Name の `日本語_sample-01.md` が送信される。

#### 長文と改行を保持する

1. `商品一覧（β版）`、`SKU-001`、`税込￥1,280`、`2026/09/15` を含むケースを入力する。
2. 3 つ以上の手順と、全角・半角が混在する 3 つ以上の確認項目を入力する。
3. `Preview CSV` ボタンを選択する。

* [ ] `Validation Steps` セル内で各手順が別々の行に表示される。
* [ ] `Checkpoints` セル内で各確認項目が別々の行に表示される。
* [ ] 日本語の長文が隣の列へ重なったり、途中で欠けたりしない。
* [ ] 半角英数字の連続文字列 `VeryLongProductCode-ABC123456789` が列幅を壊さない。
* [ ] テーブル領域を横スクロールしても、列の対応関係を確認できる。

### 入力エラー
#### Markdown 未入力を拒否する

1. Markdown エディターを空欄、または全角スペース `　` と半角スペースだけにする。
2. `Preview CSV` ボタンを選択する。

* [ ] リクエストが失敗し、画面上にエラーが表示される。
* [ ] エラーに Markdown が空であることが示される。
* [ ] 直前のプレビューが新しい結果として残らない。

#### ケースがない Markdown を処理する

1. `## 見出しだけ` と `* [ ] 確認項目だけ` を入力し、`####` のケース見出しを含めない。
2. `Preview CSV` ボタンを選択する。

* [ ] リクエスト完了後にステータスが `Done` になる。
* [ ] 列ヘッダーは表示される。
* [ ] 存在しないケースが生成されず、行がないことが分かる表示になる。

## アクセシビリティとレスポンシブ表示
### 基本操作
#### キーボードだけで操作する

1. ページを再読み込みし、キーボードだけで各コントロールへ移動する。
2. Submit ボタンにフォーカスを移してフォームを送信する。

* [ ] Source Name と Markdown の入力欄に見えるラベルがある。
* [ ] Submit ボタンへフォーカスでき、キーボードで実行できる。
* [ ] 成功ステータスとエラーメッセージを支援技術で確認できる。

#### 狭い画面幅で表示する

1. ブラウザーの viewport を約 `375px` 幅に設定する。
2. ページを再読み込みし、全角・半角混在の長文ケースでプレビューする。

* [ ] エディターとプレビューが重ならず操作できる。
* [ ] テーブル領域をスクロールして内容を確認できる。
* [ ] 必須の入力欄とボタンが viewport の外へ欠けない。
* [ ] 全角文字が不自然に切断されず、半角文字列も読める状態で表示される。
